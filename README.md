# Wolff Property — Findings Report

A working-draft findings report on the Jackson Township / Wolff Property approval cycle, published to a stable URL for review by collaborators.

The report is hosted at: `https://bnuckols13.github.io/wolff-property-report/`

This repository contains only the report viewer (a single self-contained HTML file). The underlying investigation workspace — evidence captures, methodology, journal entries, partner-witness materials, refusal flags — lives in a separate private repository and is not published here.

The viewer is set to `noindex,nofollow` so search engines do not crawl it. Anyone who has the URL can read it; the page is not discoverable through search.
